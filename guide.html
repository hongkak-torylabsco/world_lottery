번호 생성과 복사

국가, 복권, 생성 수량을 고른 뒤 번호를 생성하세요. 생성 결과에서 한 조합 또는 전체를 복사할 수 있습니다. 초기화하면 화면의 조합이 지워집니다. 이미 복사한 내용은 기기의 클립보드에 남을 수 있습니다.

구매 선택 번호와 추첨 보너스

예를 들어 미국 Powerball의 빨간 공은 본번호와 함께 선택하는 별도 번호입니다. 한국 로또 6/45의 보너스는 추첨에서만 결정됩니다. 생성 결과에는 구매할 때 고르는 번호만 표시합니다. 복권마다 적용되는 규칙과 공식 출처는 생성기의 규칙 카드에서 확인할 수 있습니다.

서버에서 번호를 만드는 방식

번호는 서버에서 Web Crypto로 생성합니다. 같은 요청으로 생성한 묶음에는 서로 다른 구매 조합이 표시됩니다.

자주 묻는 질문

생성한 번호가 당첨 가능성을 높이나요?
공정한 추첨에서는 같은 게임의 모든 유효한 조합이 같은 1등 당첨 확률을 가집니다. 과거 당첨 빈도로 다음 추첨을 예측할 수 없습니다.
서로 다른 게임 줄에 같은 번호가 나올 수 있나요?
다른 조합에 같은 숫자가 나올 수 있습니다. 같은 묶음에서는 구매 조합 전체가 중복되지 않습니다. 별도 번호 풀이 있는 게임은 본번호와 별도 번호의 숫자가 같을 수도 있습니다.

책임 있는 복권 이용

거주 지역의 법정 연령과 규정을 확인하세요. 구입한다면 잃어도 생활에 지장이 없는 금액을 미리 정하고, 손실을 만회하려고 지출을 늘리지 마세요. 지출이나 이용을 조절하기 어렵다면 잠시 중단하고 지역의 도박 문제 상담 서비스를 이용하세요.

English

Select a country, game and quantity, then generate, copy or clear the results. The generator includes the main numbers and any separate numbers you choose on a ticket. The server generates the numbers using Web Crypto. Random picks do not improve the odds. Observe local age rules, set a spending limit and avoid chasing losses.
