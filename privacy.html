번호 생성과 클립보드

번호를 생성할 때 선택한 복권, 수량, 생성 방식을 Cloudflare Worker로 보내고 생성된 번호를 받습니다. 복사를 선택하면 번호 텍스트가 기기의 클립보드에 기록됩니다. 화면을 초기화해도 기기 클립보드의 복사본은 남을 수 있습니다. 사이트에는 회원가입과 결제 기능이 없습니다.

번호 기록과 즐겨찾기

이미지 저장을 선택하면 번호 조합을 기기에서 PNG로 만들어 다운로드합니다. 번호 공유를 선택하면 번호와 사이트 주소(지원되는 경우 PNG 포함)가 기기의 공유 기능에 전달됩니다. 공유 대상은 사용자가 선택하며, 공유한 데이터에는 해당 서비스의 정책이 적용됩니다. 기기에서 공유 기능을 제공하지 않으면 번호와 사이트 주소를 클립보드에 복사합니다.

생성 기록과 즐겨찾기는 이 사이트에 대한 브라우저 저장소(localStorage)에 보관됩니다. 저장 항목은 번호 조합, 국가·게임 식별자, 생성 당시 규칙, 기록 식별자, 생성·즐겨찾기 시각입니다. 생성기는 이를 외부 서버에 전송하지 않습니다. 화면에서 기록을 삭제하거나 즐겨찾기를 해제할 수 있으며, 브라우저에서 사이트 데이터를 지우면 둘 다 삭제됩니다. 서로 다른 기기나 브라우저 간에는 동기화되지 않습니다.

사이트 제공과 보안

사이트 파일은 Cloudflare Pages가 전송합니다. Cloudflare는 요청 처리와 호출 제한을 위해 IP 주소, 요청 URL과 같은 기술 정보를 처리할 수 있습니다. Cloudflare의 처리 방식은 Cloudflare 개인정보처리방침에서 확인할 수 있습니다.

Google AdSense

AdSense 코드가 적용된 버전의 생성기 페이지를 열면 브라우저가 Google에 스크립트를 요청합니다. 그 과정에서 방문 URL, IP 주소 등 기술 정보가 Google에 전송될 수 있습니다. 광고가 제공되는 경우 Google과 광고 기술 제공업체는 쿠키를 설정하거나 읽고 웹 비콘, IP 주소 또는 기타 식별자를 사용해 광고를 제공·측정하고 부정 활동을 방지할 수 있습니다. 개인 맞춤 광고에 적용되는 처리는 설정과 동의에 따라 달라질 수 있습니다.

Google이 파트너 사이트의 정보를 사용하는 방법과 Google 내 광고 센터에서 자세한 내용과 맞춤 광고 설정을 확인할 수 있습니다. 브라우저 설정에서 쿠키를 관리할 수 있습니다. 사이트에서 광고 동의 설정을 제공하는 경우 해당 설정을 통해 선택을 변경할 수 있습니다.

외부 링크와 문의

피드백 및 질문 양식을 제출하면 유형, 분류, 선택 제목, 언어, 내용, 선택 이메일, 접수 번호와 접수 시각이 Cloudflare D1에 저장됩니다. 인증된 운영자가 문의 상태, 내부 메모와 답변을 관리하며, 이메일이 제공된 경우 직접 답변할 수 있습니다. 복권 출처나 공개 GitHub 링크를 열면 해당 서비스의 개인정보처리방침이 적용됩니다.

자동 제출을 줄이기 위해 Cloudflare Turnstile을 사용하고, IP 주소에서 만든 단기 식별자로 접수 횟수를 제한합니다. 공개 Q&A에는 운영자가 별도로 작성해 승인한 질문과 답변을 게시합니다.

개인정보 또는 문의 삭제를 요청하려면 문의 양식에 접수 번호를 알려 주세요. 운영자가 이메일과 비공개 내용을 삭제하거나 문의 전체를 삭제할 수 있습니다. 보관 기간과 개인정보 관련 법적 문구는 운영 배포 전에 운영자가 확정할 항목입니다.
