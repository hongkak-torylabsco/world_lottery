오류와 개선 제안

World Lottery GitHub Issues에서 기존 제보를 찾아보고, 새 제보가 필요하면 GitHub 계정으로 이슈를 등록할 수 있습니다.

규칙 오류는 복권 이름, 문제가 있는 안내, 운영사의 근거 링크를 함께 알려 주세요. 기능 오류는 문제가 발생한 화면, 사용 언어와 브라우저, 재현 순서를 알려 주시면 확인에 도움이 됩니다.

개인정보가 포함된 문의

GitHub Issues는 공개 게시판입니다. 이름, 연락처, 계정 정보, 복권 티켓 사진을 올리지 마세요. 개인정보가 포함된 문의에 사용할 비공개 연락처는 현재 공개되어 있지 않습니다.

English

Use the public GitHub Issues board linked above to report errors, accessibility issues or rule corrections. Include the lottery name, official source or reproduction steps where applicable. Keep personal and account details out of public posts. A private contact channel is not currently listed.

日本語

上記の公開GitHub Issuesで不具合、アクセシビリティの問題、ルールの訂正を報告できます。宝くじ名、公式出典、再現手順などを添えてください。個人情報やアカウント情報を投稿しないでください。非公開の連絡先は現在掲載していません。

Português (Brasil)

Use o GitHub Issues público indicado acima para relatar falhas, questões de acessibilidade ou correções de regras. Envie o nome da loteria, a fonte oficial ou os passos para reproduzir o problema. Não publique dados pessoais ou da conta. Não há um canal privado de contato publicado.
